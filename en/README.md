# Welcome to Semantix

**Semantix** is an AI-powered data intelligence platform that lets your team query databases, explore data, build dashboards, and automate data workflows — no SQL expertise required.

## What can you do with Semantix?

- **Ask in plain language** — Semantix translates questions to SQL and returns results instantly
- **Data Portal** — browse and export data using pre-built templates with filter parameters, no code needed
- **Build dashboards** — drag-and-drop charts, scorecards, and tables
- **Connect any database** — PostgreSQL, MySQL, BigQuery, Snowflake, ClickHouse, Google Sheets, and more
- **Data Pipelines** — automate data sync on a schedule between sources and destinations
- **AI Assistants** — configure multiple AI assistants with different personalities, contexts, and providers
- **Advanced analytics** — Cohort, RFM, Funnel, Growth, and Vintage analysis out of the box
- **Automated alerts & reports** — get notified on Telegram, Zalo, or Microsoft Teams
- **Public API** — embed dashboards or query data from your own apps
