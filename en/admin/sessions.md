# Sessions

**Navigate to:** Admin → Monitoring → Sessions

Sessions lets Admins view and manage active login sessions — including login history, devices, IP addresses, and the ability to remotely terminate sessions.

## Key Features

- View list of currently logged-in users
- View login history per user (count, IP, device, timestamp)
- Terminate a specific user's session remotely
- Terminate all sessions in security emergencies
- Filter by login date range

## Viewing Active Sessions

1. Go to **Admin → Monitoring → Sessions**
2. The page shows active users with:

| Information | Description |
|-------------|-------------|
| **Email / Name** | User identity |
| **Last Login** | Most recent login timestamp |
| **IP Address** | Connection IP |
| **User Agent** | Browser / device |
| **Login Count** | Total logins in the period |

## Terminating Sessions

- **Terminate Session**: Click the **Terminate** button next to a user to log them out immediately.
- **Terminate All Sessions**: End all active sessions — use in security emergency situations.

## Date Range Filter

Use the **Date Range** picker to view login history within a specific time window.

## Notes

This feature is Admin-only. Terminate session actions are recorded in Audit Logs.
