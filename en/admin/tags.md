# Tags

**Navigate to:** Admin → Access → Tags

Tags are classification labels for resources in the system (Pipelines, Data Templates, AI Assistants, Models...). They help organize, search, and filter resources quickly as your system grows.

## Use Cases

- Label resources by topic (e.g., `sales`, `hr`, `finance`)
- Quick filtering by tag in Pipelines, Templates, Assistants lists
- Group resources for different teams or departments

## Managing Tags

1. Go to **Admin → Access → Tags**
2. View all tags and their resource usage counts
3. Click **New Tag** to create a new tag
4. Fill in **Name**, **Color**, and **Description**
5. Click **Save**

## Assigning Tags to Resources

Tags can be assigned when creating or editing any resource that supports tagging (Pipeline, Data Template, AI Assistant, Model...). Look for the **Tags** field in the edit form.

## Filtering by Tag

On list pages (Pipelines, Templates...), use the **Tag** filter in the toolbar to show only resources with a specific tag.
