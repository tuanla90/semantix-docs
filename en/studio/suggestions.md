# Suggestions

**Navigate to:** Studio → DABI → Suggestions

Suggestions manages sample questions shown to users in AI Chat. Admins and Approvers can review, approve, or reject suggestions submitted by users.

## Role of Suggestions

- Users in AI Chat can propose sample questions for their department
- Admins or Approvers review and approve suitable suggestions
- Approved suggestions appear in the chat interface to guide new users

## Suggestion Status

| Status | Meaning |
|--------|---------|
| **Pending** | Awaiting review |
| **Approved** | Approved — displayed in chat |
| **Rejected** | Declined |

## Managing Suggestions

1. Go to **Studio → DABI → Suggestions**
2. Use the **Status** filter to view by status (Pending / Approved / Rejected)
3. Search by question content
4. Click a suggestion to view details
5. Click **Approve** or **Reject** (optionally add a review note)

## Sorting and Filtering

- Sort by: Created date, Status, Type
- Quick filter tabs: **All / Pending / Approved / Rejected**
- Pagination for high-volume review

## Notes

- Permissions: Requires `edit_suggestion` permission to approve/reject.
- Keeping Suggestions updated helps new users understand what they can ask about.
