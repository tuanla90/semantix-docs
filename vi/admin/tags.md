# Tags (Nhãn)

**Điều hướng:** Admin → Access → Tags

Tags là các nhãn phân loại tài nguyên trong hệ thống (Pipelines, Data Templates, AI Assistants, Models...). Tags giúp tổ chức, tìm kiếm và lọc tài nguyên nhanh hơn khi hệ thống có nhiều đối tượng.

## Công Dụng

- Gắn nhãn tài nguyên theo chủ đề (ví dụ: `sales`, `hr`, `finance`)
- Lọc nhanh theo tag trong danh sách Pipelines, Templates, Assistants...
- Phân nhóm tài nguyên cho các bộ phận khác nhau

## Quản Lý Tags

1. Vào **Admin → Access → Tags**
2. Xem danh sách tất cả tags và số lượng tài nguyên đang dùng mỗi tag
3. Nhấn **New Tag** để tạo tag mới
4. Điền **Name**, **Color** (màu nhãn) và **Description**
5. Nhấn **Save**

## Gán Tag cho Tài Nguyên

Tags có thể được gán khi tạo hoặc chỉnh sửa bất kỳ tài nguyên nào hỗ trợ tag (Pipeline, Data Template, AI Assistant, Model...). Tìm trường **Tags** trong form chỉnh sửa.

## Lọc Theo Tag

Trên các trang danh sách (Pipelines, Templates...), dùng bộ lọc **Tag** trên thanh công cụ để chỉ hiển thị tài nguyên có tag cụ thể.
