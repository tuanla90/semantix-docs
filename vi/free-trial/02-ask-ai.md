# Bước 2 — Chat với Số Liệu

Đây là tính năng cốt lõi của Semantix: **hỏi dữ liệu bằng tiếng Việt thông thường, nhận biểu đồ trong 5 giây**.

---

## Mở AI Chat

Nhấn vào **AI Chat** trên thanh điều hướng phía trên.

Bạn sẽ thấy giao diện chat — nhập câu hỏi của bạn vào ô phía dưới, nhấn Enter.

---

## Ví Dụ Câu Hỏi Thực Tế

Dưới đây là các câu hỏi mẫu bạn có thể thử ngay. Thay tên cột/sản phẩm bằng dữ liệu thực của bạn.

### Theo dõi doanh thu

```
Doanh thu 7 ngày gần nhất là bao nhiêu?
```
```
So sánh doanh thu tháng này với tháng trước
```
```
Ngày nào trong tuần có doanh thu cao nhất?
```

### Theo dõi sản phẩm

```
Top 5 sản phẩm bán chạy nhất tháng này
```
```
Sản phẩm nào đang tồn kho nhiều nhất?
```
```
Sản phẩm nào có doanh thu giảm so với tháng trước?
```

### Theo dõi đơn hàng

```
Có bao nhiêu đơn hàng hôm nay?
```
```
Tỷ lệ đơn hàng bị hủy là bao nhiêu phần trăm?
```
```
Kênh bán hàng nào mang lại nhiều đơn nhất?
```

### Phân tích chi phí / quảng cáo

```
Chi phí quảng cáo Facebook tháng này là bao nhiêu?
```
```
Chiến dịch quảng cáo nào đang tốn tiền nhất?
```

## AI Trả Lời Như Thế Nào?

Semantix sẽ tự động:
1. Hiểu câu hỏi của bạn
2. Tạo truy vấn dữ liệu tương ứng
3. Trả về kết quả dưới dạng **biểu đồ** hoặc **bảng số liệu**
4. Kèm theo diễn giải ngắn bằng tiếng Việt

Bạn có thể hỏi tiếp để đào sâu hơn, ví dụ:
```
Tại sao doanh thu ngày thứ 3 lại thấp như vậy?
```
```
Chỉ lấy dữ liệu kênh Shopee thôi
```
```
Vẽ thành biểu đồ cột thay vì biểu đồ đường
```

## Mẹo Hỏi Hiệu Quả

| Nên | Không nên |
|-----|-----------|
| Hỏi cụ thể: *"Doanh thu tháng 6 theo từng tuần"* | Hỏi mơ hồ: *"Cho tôi biết số liệu"* |
| Dùng đúng tên cột có trong file: *"cột 'Kênh bán hàng'"* | Đặt tên không trùng với dữ liệu thực |
| Hỏi từng câu một, có trọng tâm | Hỏi 5 thứ cùng lúc trong 1 câu |
| Hỏi thêm nếu kết quả chưa đúng | Bỏ cuộc nếu lần đầu chưa chính xác |

> **Lưu ý gói Free:** Bạn có **50 lượt hỏi/tháng**. Mỗi lần nhấn Enter là 1 lượt. Dùng thử có chọn lọc để tận dụng hết giá trị.
